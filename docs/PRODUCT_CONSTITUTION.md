# Product Constitution

## Product Thesis

Little Shots OS exists to preserve the emotional context of family relationships across years while making studio operations more consistent, trustworthy, intelligent, and scalable.

The long-term product stack is:
- Little Shots OS: studio operating system
- Little Shots AI: intelligence layer
- Family Memory Platform: ongoing family product
- Memory Graph: longitudinal relationship and memory model
- Future SaaS: multi-studio commercial platform

## North Star

Optimize for active family memory relationships, not feature count.

A successful system helps Little Shots preserve more meaningful stages for a family over time while maintaining care, privacy, safety, clarity, and quality.

## Product Domains

### Studio OS
Leads, CRM, consultations, bookings, shoots, production, editing, delivery, team operations.

### Family OS
Families, parents, children, communication preferences, portal, relationship context.

### Memory OS
Memory profiles, milestones, timelines, galleries, albums, heirlooms, future memory opportunities.

### Business OS
Packages, quotes, payments, finance, KPIs, marketing, commercial controls.

### AI OS
Memory Guide, sales support, studio assistance, concierge, forecasting, intelligence.

### Founder OS
Executive dashboards, risk signals, brand governance, capacity, growth, strategic insights.

## Non-Goals for Current Foundation

Do not prioritize before core operating foundations are stable:
- native mobile apps
- autonomous sales agents
- full custom gallery replacement
- marketplace
- SaaS billing
- advanced generative image systems
- speculative social/community features
