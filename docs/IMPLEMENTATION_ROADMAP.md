## Phase 2 — Studio Operations
Calendar, shoot planning, team scheduling, production, editing, selection, heirlooms, delivery, QC, operational analytics, AI Studio Assistant.

## Phase 3 — Family Memory Platform
Memory Timeline, Family Vault, milestones, future recommendations, native galleries, portal 2.0, subscriptions, referrals, WhatsApp Family Concierge.

## Phase 4 — Intelligence Platform
Forecasting, lead scoring, capacity prediction, creative intelligence, album assistance, culling assistance, Founder intelligence, marketing intelligence, style intelligence.

## Phase 5 — SaaS
Studio onboarding, tenant provisioning, subscription billing, configuration, studio administration, multi-studio analytics, platform support and API ecosystem.

## Scope Rule

Do not implement a later-phase feature to make a current-phase feature more interesting. Implement only what removes a current dependency or satisfies an approved milestone.
